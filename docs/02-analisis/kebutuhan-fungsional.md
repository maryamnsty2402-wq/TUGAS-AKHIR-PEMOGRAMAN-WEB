# Analisis Kebutuhan Fungsional

Kebutuhan fungsional merupakan kebutuhan yang menjelaskan fungsi-fungsi yang harus tersedia dan dapat dijalankan oleh Sistem Pemesanan Buket Berbasis Web. Kebutuhan ini disusun berdasarkan wireframe yang telah dirancang, sehingga setiap halaman memiliki fungsi yang sesuai dengan tujuan penggunaannya.

## 1. Kebutuhan Fungsional Pelanggan

| Kode | Halaman | Kebutuhan Fungsional |
|---|---|---|
| KF-01 | Beranda | Sistem menampilkan halaman utama yang berisi informasi usaha, pengenalan website, dan navigasi menuju halaman lainnya. |
| KF-02 | Katalog Buket | Sistem menampilkan daftar produk buket beserta informasi produk dan harga. |
| KF-03 | Detail Produk | Sistem menampilkan detail produk yang dipilih pelanggan, termasuk informasi, gambar, harga, dan deskripsi produk. |
| KF-04 | Keranjang | Sistem menampilkan produk yang dipilih, jumlah produk, harga, dan total harga pesanan. |
| KF-05 | Keranjang | Sistem memungkinkan pelanggan mengubah jumlah produk atau menghapus produk dari keranjang. |
| KF-06 | Checkout | Sistem menyediakan formulir untuk memasukkan data pemesan dan informasi yang diperlukan untuk pengiriman pesanan. |
| KF-07 | Checkout | Sistem menampilkan ringkasan pesanan dan total harga sebelum pesanan dikonfirmasi. |
| KF-08 | Checkout | Sistem memungkinkan pelanggan melakukan pemesanan tanpa membuat akun atau login. |
| KF-09 | Pembayaran | Sistem menampilkan informasi pembayaran yang diperlukan untuk menyelesaikan transaksi. |
| KF-10 | Pembayaran | Sistem menyediakan fasilitas untuk mengunggah bukti pembayaran. |
| KF-11 | Konfirmasi Pesanan | Sistem menampilkan informasi keberhasilan pemesanan dan kode pesanan setelah pesanan berhasil dibuat. |
| KF-12 | Lacak Pesanan | Sistem menyediakan formulir untuk memasukkan kode pesanan dan nomor WhatsApp guna mencari pesanan. |
| KF-13 | Lacak Pesanan | Sistem menampilkan informasi dan status pesanan apabila data yang dimasukkan sesuai. |
| KF-14 | Lacak Pesanan | Sistem menampilkan pemberitahuan apabila kode pesanan atau nomor WhatsApp yang dimasukkan tidak sesuai atau pesanan tidak ditemukan. |

## 2. Kebutuhan Fungsional Admin

| Kode | Halaman | Kebutuhan Fungsional |
|---|---|---|
| KF-15 | Login Admin | Sistem menyediakan halaman login untuk admin agar dapat mengakses halaman pengelolaan website. |
| KF-16 | Dashboard Admin | Sistem menampilkan ringkasan informasi mengenai produk, pesanan, dan pembayaran yang diperlukan admin. |
| KF-17 | Kelola Produk | Sistem memungkinkan admin menambahkan produk buket baru. |
| KF-18 | Kelola Produk | Sistem memungkinkan admin mengubah informasi produk yang telah tersedia. |
| KF-19 | Kelola Produk | Sistem memungkinkan admin menghapus produk yang tidak lagi tersedia. |
| KF-20 | Kelola Produk | Sistem menampilkan daftar produk yang telah dimasukkan ke dalam sistem. |
| KF-21 | Kelola Pesanan | Sistem menampilkan daftar pesanan pelanggan yang masuk. |
| KF-22 | Kelola Pesanan | Sistem memungkinkan admin melihat detail pesanan pelanggan. |
| KF-23 | Kelola Pesanan | Sistem memungkinkan admin memperbarui status pesanan sesuai proses pengerjaan. |
| KF-24 | Kelola Pembayaran | Sistem menampilkan informasi pembayaran dan bukti pembayaran yang diunggah pelanggan. |
| KF-25 | Kelola Pembayaran | Sistem memungkinkan admin memeriksa dan memverifikasi pembayaran pelanggan. |

## 3. Kebutuhan Fungsional Tambahan

1. Sistem menyimpan data pesanan pelanggan agar dapat dikelola oleh admin.
2. Sistem menghasilkan kode pesanan yang dapat digunakan pelanggan untuk melacak pesanan.
3. Sistem menghubungkan data pesanan dengan informasi pelanggan yang dimasukkan saat checkout.
4. Sistem menyimpan informasi status pesanan dan pembayaran agar dapat diperbarui dan ditampilkan kembali.
5. Sistem menyediakan navigasi antarhalaman agar pelanggan dan admin dapat menggunakan website sesuai alur yang dirancang.
